MINDLY FIXED - QUICK START

FRONTEND
1. Open terminal in this folder.
2. npm install
3. npm run dev

BACKEND
1. Open a second terminal.
2. cd backend
3. Activate your existing venv, or create one:
   python -m venv venv
   .\venv\Scripts\Activate.ps1
4. pip install -r requirements.txt
5. python manage.py migrate
6. python manage.py runserver

LOCAL DREAM AI
Open a THIRD terminal and start your llama-server on:
http://127.0.0.1:8080

The fixed AI connector first detects the model exposed by llama-server.
If model discovery is unavailable, it falls back to the model name
mindly-dream-ai.
